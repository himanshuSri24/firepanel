# Store assets

- `screenshots/raw/` — screenshots exactly as captured, any size. Not published.
- `screenshots/` — the same shots padded to the 1280x800 canvas the Chrome Web
  Store expects. These are the ones to upload.

Capture into `raw/`, then run `sh scripts/normalize-screenshots.sh`.

The icon uploaded to the store is `public/icons/icon128.png`, generated by
`npm run icons`.
